# proyecto-github

Este proyecto trata sobre el trabajo con ramas de github con el fin de poder implementar cambios de manera controlada y segura, como se ve en este archivo 

se crearán y se eliminarán las ramas necesarias para el funcionamiento del proyecto.

1. se creará una rama llamada html-dom desde la rama main la cual se encargará de la maquetación del proyecto.
2. se creará una rama llamada header desde la rama html-dom la cual se encargará de la creación del header del proyecto.
3. se creará una rama llamada footer desde la rama html-dom la cual se encargará de la creación del footer del proyecto.
4. se creará una rama llamada main-content desde la rama html-dom la cual se encargará de la creación del contenido principal del proyecto.

cada cambio se realizara en un commit distinto.
las ramas deben estar separadas una de otras y no deben tener cambios de otras ramas.

los cambios que se realicen es este archivo obedecen a la rama 'main'.
